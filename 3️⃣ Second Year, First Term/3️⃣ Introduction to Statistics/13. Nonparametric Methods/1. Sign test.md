# 13.1 Sign Test ⭐⭐⭐

**Rating Justification:**

- **Understanding (⭐ 4/5):** This is the simplest possible statistical test. It strips away magnitude (how _much_ better?) and looks only at direction (better or worse?). It is the nonparametric alternative to the One-Sample or Paired T-test.
    
- **Exam (⭐ 3/5):** Calculation questions are common because they are easy to solve by hand using the Binomial Distribution (or a Z-approximation for large samples).
    

---

### **1. The Logic of Nonparametric Statistics**

Before defining the test, we must define the category.

- **Parametric Tests (e.g., T-Test):** Assume the data follows a specific distribution (usually Normal) and analyze parameters like the Mean ($\mu$) and Variance ($\sigma^2$).
    
- **Nonparametric Tests:** Make **no assumptions** about the shape of the population distribution ("Distribution-free"). They analyze **Medians** or **Ranks** instead of Means.
    
- **When to use:** When sample sizes are small ($n < 30$) AND the data is clearly non-normal (skewed) or ordinal.
    

---

### **2. The Sign Test Procedure**

The **Sign Test** is used to test the hypothesis about the **Median** of a population. It is most commonly applied to **Paired Data** (Before vs. After).

- **The Transformation:** We convert the raw data into "Signs."
    
    - If $After > Before$: Record a Plus ($+$).
        
    - If $After < Before$: Record a Minus ($-$).
        
    - If $After = Before$: **Discard** the data point (Tie).
        
- **Hypotheses:**
    
    - $H_0$: Median Difference $= 0$. (Probability of $+$ is 0.5).
        
    - $H_1$: Median Difference $\neq 0$. (Probability of $+$ is not 0.5).
        

---

### **3. The Calculation (Binomial Method)**

Under the Null Hypothesis, seeing a ($+$) is like flipping a fair coin (Heads).

If we have $n$ non-tied pairs, the number of pluses ($X$) follows a Binomial Distribution with $p=0.5$.

- Small Samples ($n \le 25$):
    
    Calculate the exact binomial probability.
    
    $$P(X \ge k) = \sum \binom{n}{x} (0.5)^x (0.5)^{n-x}$$
    
    - _Example:_ In 10 patients, 9 improved ($+$) and 1 worsened ($-$).
        
    - $P(9 \text{ or } 10) = \binom{10}{9}(0.5)^{10} + \binom{10}{10}(0.5)^{10} \approx 0.011$.
        
    - Since $0.011 < 0.05$, reject $H_0$.
        

---

### **4. Large Sample Approximation (Normal)**

If $n > 25$, the Binomial distribution converges to the Normal distribution. We use a Z-score.

- Formula:
    
    $$Z = \frac{(X \pm 0.5) - 0.5n}{0.5\sqrt{n}}$$
    
    - $X$: The number of pluses (or minuses, whichever is fewer for one-tailed).
        
    - $0.5n$: The expected number of pluses (half the sample).
        
    - $0.5\sqrt{n}$: The standard deviation of the binomial.
        
    - $\pm 0.5$: Continuity Correction (Subtract 0.5 if $X > 0.5n$, Add 0.5 if $X < 0.5n$).
        

---

### **Important Notes, Tips & Facts**

- **Wasteful:** The Sign Test is statistically **inefficient**. If Patient A improves by 1 point and Patient B improves by 100 points, the Sign Test treats them exactly the same (both are "$+$"). It ignores the _magnitude_ of the change.
    
- **Use Case:** Only use this if the data is so messy (e.g., nominal/ordinal) that you cannot measure the magnitude, or if the distribution is wildly skewed. If you _can_ rank the magnitude, use the **Wilcoxon Signed-Rank Test** (Subtopic 13.2) instead.
