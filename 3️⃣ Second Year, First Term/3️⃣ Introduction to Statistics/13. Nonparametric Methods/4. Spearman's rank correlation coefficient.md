# 13.4 Spearman's Rank Correlation Coefficient ⭐⭐⭐⭐

**Rating Justification:**

- **Understanding (⭐ 4/5):** This is the nonparametric equivalent of the Pearson correlation coefficient ($r$). While Pearson measures _linear_ relationships (straight lines), Spearman measures _monotonic_ relationships (trends that go in one direction, even if curved).
    
- **Exam (⭐ 4/5):** This is a very common calculation question. It is often paired with questions about data that has outliers or is ordinal (ranked), where the standard Pearson formula would fail.
    

---

### **1. Purpose and Definition**

**Spearman's Rho ($\rho$ or $r_s$)** assesses how well the relationship between two variables can be described using a **monotonic function**.

- **Pearson ($r$):** Assumes linearity and interval data. Sensitive to outliers.
    
- **Spearman ($r_s$):** Assumes only that if $X$ goes up, $Y$ goes up (or down). It works on **Ranks**, not raw values. It is robust to outliers.
    
- **Scenario:** Comparing "Class Rank in Math" vs. "Class Rank in English." The data is already ordinal, so Pearson is invalid. You must use Spearman.
    

---

### **2. The Calculation Procedure**

To calculate $r_s$ manually, we convert the raw data into ranks and look at the difference between them.

Step 1: Rank the Data

Rank the X values from 1 to $n$. Rank the Y values from 1 to $n$.

- _Ties:_ Assign the average rank (e.g., if ranks 2 and 3 are tied, both get 2.5).
    

Step 2: Calculate Differences ($d_i$)

For each pair, calculate the difference between the two ranks:

$$d_i = Rank(X_i) - Rank(Y_i)$$

Step 3: Square the Differences ($d_i^2$)

Square each difference to remove negatives.

Step 4: The Formula

$$r_s = 1 - \frac{6 \sum d_i^2}{n(n^2 - 1)}$$

- $n$: The number of pairs.
    
- $\sum d_i^2$: The sum of the squared rank differences.
    
- $6$: A mathematical constant that never changes.
    

---

### **3. Interpretation**

The value of $r_s$ ranges from **-1 to +1**, just like Pearson's $r$.

- **$r_s = +1$:** Perfect positive monotonic correlation. (X increases $\to$ Y increases).
    
- **$r_s = -1$:** Perfect negative monotonic correlation. (X increases $\to$ Y decreases).
    
- **$r_s = 0$:** No monotonic correlation. (Random scatter).
    

---

### **4. Example Calculation**

- **Data:**
    
    - Student A: Math Rank = 1, English Rank = 2 ($d = -1, d^2 = 1$)
        
    - Student B: Math Rank = 2, English Rank = 1 ($d = 1, d^2 = 1$)
        
    - Student C: Math Rank = 3, English Rank = 3 ($d = 0, d^2 = 0$)
        
- **Calculation:**
    
    - $n = 3$.
        
    - $\sum d^2 = 1 + 1 + 0 = 2$.
        
    - $r_s = 1 - \frac{6(2)}{3(9-1)} = 1 - \frac{12}{24} = 1 - 0.5 = 0.5$.
        

---

### **Important Notes, Tips & Facts**

- **When to choose Spearman over Pearson:**
    
    1. **Non-Linearity:** If the scatterplot shows a curve (e.g., exponential growth), Pearson will underestimate the relationship. Spearman will capture it perfectly as long as it never reverses direction.
        
    2. **Outliers:** If one person has a massive income that distorts the mean, Pearson breaks. Spearman converts that "billionaire" to just "Rank 1," neutralizing the outlier's effect.
        
    3. **Ordinal Data:** If your data is survey responses ("Strongly Agree" to "Strongly Disagree"), you cannot calculate a mean, so you must use Spearman.
