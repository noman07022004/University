---

### **1. The Structure of the Output**

Although different software packages look slightly different, the standard regression output is almost always divided into three main tables:

1. **Model Summary:** Overall fit ($R^2$).
    
2. **ANOVA Table:** Significance of the whole model ($F$).
    
3. **Coefficients Table:** Specifics of the line ($b_0, b_1$) and their significance ($t$).
    

---

### **2. Table 1: Model Summary (Goodness of Fit)**

This table tells you how well the model explains the data.

|**Model**|**R**|**R Square**|**Adjusted R Square**|**Std. Error of the Estimate**|
|---|---|---|---|---|
|1|.762|**.581**|.575|4.23|

- **R:** The multiple correlation coefficient. In simple regression, this is just $|r|$.
    
- **R Square ($R^2$):** The coefficient of determination.
    
    - _Interpretation:_ "58.1% of the variance in the dependent variable is explained by the model."
        
- **Adjusted R Square:** A modified version of $R^2$ that penalizes you for adding useless variables. (More relevant in true Multiple Regression).
    
- **Std. Error of the Estimate ($S_e$):** The average distance of data points from the regression line (in real units).
    

---

### **3. Table 2: ANOVA (F-Test)**

This table tests if the model as a whole is better than nothing (i.e., better than just guessing the mean).

|**Model**|**Sum of Squares**|**df**|**Mean Square**|**F**|**Sig.**|
|---|---|---|---|---|---|
|Regression|1450.2|1|1450.2|**25.4**|**.000**|
|Residual|2340.5|48|57.1|||
|Total|3790.7|49||||

- **F-Statistic:** Ratio of Mean Square Regression to Mean Square Residual ($1450.2 / 57.1 = 25.4$).
    
- **Sig. (P-value):** If this is $< 0.05$, the model is statistically significant.
    
    - _Note:_ In Simple Regression (1 predictor), this P-value is identical to the T-test P-value for the slope.
        

---

### **4. Table 3: Coefficients (The Critical Table)**

This is where you find the numbers to build your equation $\hat{y} = b_0 + b_1 x$.

|**Model**|**Unstandardized Coefficients (B)**|**Std. Error**|**Standardized Coefficients (Beta)**|**t**|**Sig.**|
|---|---|---|---|---|---|
|**(Constant)**|**12.532**|2.105||5.95|.000|
|**StudyHours**|**4.215**|0.820|.762|**5.14**|**.000**|

- **Unstandardized B (The Estimates):**
    
    - **(Constant):** This is the **Intercept ($b_0$)**.
        
    - **StudyHours:** This is the **Slope ($b_1$)**.
        
- Writing the Equation:
    
    From the bolded numbers above, the equation is:
    
    $$\hat{y} = 12.532 + 4.215(\text{StudyHours})$$
    
- **Std. Error:** The uncertainty of the coefficient ($SE_b$).
    
- **t (T-statistic):** Calculated as $B / Std.Error$.
    
    - _Check:_ $4.215 / 0.820 = 5.14$. (Knowing this relationship is often required to fill in blanks on exams).
        
- **Sig. (P-value):** The probability that the true slope is zero.
    
    - Since $.000 < 0.05$, StudyHours is a significant predictor.
        

---

### **Important Notes, Tips & Facts**

- **Standardized Beta ($\beta^*$):** This column shows what the slope would be if all variables were converted to Z-scores first.
    
    - _Usage:_ Useful in **Multiple** Regression to compare strength. If Beta for X1 is 0.5 and X2 is 0.8, X2 is the stronger predictor. In Simple Regression, Beta is simply equal to the correlation $r$.
        
- **Sig = .000:** This does _not_ mean the probability is zero. It means $P < 0.001$. Never write "P=0" in an exam.
    
- **Confidence Intervals:** Some outputs include a "95% Confidence Interval for B". If this interval (e.g., $2.5$ to $5.9$) does not contain 0, the variable is significant.
