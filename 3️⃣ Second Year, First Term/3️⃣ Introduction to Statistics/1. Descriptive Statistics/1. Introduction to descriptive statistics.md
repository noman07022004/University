## 1.1 Introduction to Descriptive Statistics ⭐⭐⭐

>**Rating Justification:**

>- **Exam (⭐ 3/5):** You will rarely get a long essay solely on this, but short-answer questions (e.g., "Classify this variable") and definitions are very common. Moreover, using the wrong terminology here will lose you marks in advanced questions.

### 1. Defining the Discipline

**Descriptive Statistics** is the branch of statistics concerned with the collection, organization, summarization, and presentation of data. Unlike **Inferential Statistics**, which uses data to make predictions or decisions about a larger population, descriptive statistics seeks only to describe the specific data that has been collected. It tells you "what is," not "what might be."

In an academic context, descriptive statistics serves two primary functions:

1. **Data Reduction:** Reducing a massive volume of raw numbers into a few manageable summary indices (like the average or the range).
    
2. **Pattern Recognition:** Identifying clusters, trends, or outliers that might not be visible in the raw data tables.
    

---

### 2. Population vs. Sample: The Fundamental Distinction

The most critical distinction in the introduction of statistics is the source of the data. This distinction dictates the mathematical notation you must use throughout the course.

- **Population:** The entire collection of all individuals or items of interest (e.g., "All students in the university").
    
    - A measure calculated from a population is called a **Parameter**.
        
    - _Notation:_ Greek letters are used (e.g., Mean = $\mu$, Standard Deviation = $\sigma$, Size = $N$).
        
- **Sample:** A subset of the population selected for analysis (e.g., "50 students selected randomly").
    
    - A measure calculated from a sample is called a **Statistic**.
        
    - _Notation:_ Roman/English letters are used (e.g., Mean = $\bar{x}$, Standard Deviation = $s$, Size = $n$).
        

> **Academic Rule:** In descriptive statistics, we are usually calculating _statistics_ ($\bar{x}, s$) to estimate unknown _parameters_ ($\mu, \sigma$).

---

### 3. Types of Data (Variables)

Before performing any calculation, a statistician must classify the variable type. This classification determines which mathematical operations are valid.

#### A. Categorical (Qualitative) Data

Data that describes a quality or characteristic. You cannot perform meaningful arithmetic on these (e.g., you cannot calculate the "average" eye color).

- **Examples:** Gender, Blood Type, Zip Code, Political Affiliation.
    

#### B. Numerical (Quantitative) Data

Data that represents counts or measurements. Arithmetic operations are valid. This is further divided into:

- **Discrete Variables:** Can only take specific, countable values. There are gaps between values.
    
    - _Example:_ Number of children in a family ($0, 1, 2...$ you cannot have $1.5$ children).
        
- **Continuous Variables:** Can take any value within a range. The precision is limited only by the measuring instrument.
    
    - _Example:_ Height ($170.1$ cm), Weight, Time, Temperature.
        

---

### 4. Levels of Measurement (Scales)

This hierarchy (proposed by Stanley Stevens) is the theoretical framework for choosing statistical tests. You must memorize the order from lowest information to highest information.

1. **Nominal Scale (Lowest Level):**
    
    - Data serves only as a label or name. No inherent order exists.
        
    - _Math Allowed:_ Counting (Frequency), Mode.
        
    - _Example:_ Marital Status (Single, Married, Divorced). "Married" is not "greater than" Single.
        
2. **Ordinal Scale:**
    
    - Data has a strict order/rank, but the _distance_ between ranks is unknown or unequal.
        
    - _Math Allowed:_ Median, Percentiles, Rank Correlation.
        
    - _Example:_ Likert Scale (Happy, Neutral, Unhappy), Army Ranks (General > Colonel).
        
    - _Note:_ You cannot say the difference between General and Colonel is equal to the difference between Colonel and Major.
        
3. **Interval Scale:**
    
    - Data is ordered, and the intervals between consecutive values are equal. However, there is **No True Zero** (Zero does not mean "nothing," it is just a point on the scale).
        
    - _Math Allowed:_ Addition, Subtraction, Mean, Standard Deviation.
        
    - _Example:_ Temperature in Celsius (0°C is cold, not the absence of heat), Calendar Years.
        
    - _Limitation:_ You cannot calculate ratios. 20°C is not "twice as hot" as 10°C.
        
4. **Ratio Scale (Highest Level):**
    
    - Data is ordered, intervals are equal, and there is a **True Absolute Zero** (Zero means the absence of the variable).
        
    - _Math Allowed:_ All arithmetic (including multiplication/division).
        
    - _Example:_ Height, Weight, Income, Distance. 20 meters _is_ twice as long as 10 meters.

### 5. Frequency Distributions

The first step in describing data is usually organizing raw values into a **Frequency Distribution Table**.

- **Frequency ($f$):** The number of times a value occurs.
    
- Relative Frequency ($rf$): The proportion of the total data that falls into a specific class.
    
    $$rf = \frac{f}{n}$$
    
- **Cumulative Frequency ($cf$):** The running total of frequencies. It tells you how many observations lie _below_ a certain value.
    

**Visualizing Distributions:**

- **Bar Charts:** Used for Categorical or Discrete data. Bars should have _gaps_ between them to show categories are distinct.
    
- **Histograms:** Used for Continuous data. Bars must _touch_ each other to imply continuity. The area of the bar represents the frequency.
    

---

### Important Notes, Tips & Facts

- **The "Zip Code" Trap:** Just because a variable looks like a number does not mean it is numerical. A Zip Code (e.g., 90210) is **Nominal** data. You cannot calculate the "Average Zip Code"—it is meaningless.
    
- **Likert Scales:** In social sciences, Likert scales (1 to 5 ratings) are technically **Ordinal**. However, in many academic studies, if the scale has 5+ points, researchers often treat them as **Interval** data to allow for the calculation of Means and T-tests. This is a common point of debate.
    
- **Notation matters:** If an exam question asks for the "Population Mean," you **must** write $\mu$. If you write $\bar{x}$, it is technically incorrect because that refers to a sample.
    
- **Continuous vs Discrete:** A quick test: If you can technically add a decimal and it still makes sense (e.g., age 25.5 years), it is continuous. If a decimal makes it absurd (e.g., 25.5 car accidents), it is discrete.
