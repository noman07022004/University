### **1. The Random Variable ($X$)**

In algebra, $x$ is a fixed unknown (e.g., solve for $x$ in $2x = 4$). In statistics, a **Random Variable ($X$)** is a function that assigns a numerical value to each outcome in a sample space. It is a value that is determined by chance.

- **Notation:**
    
    - **Capital $X$:** The random variable itself (the process).
        
    - **Lowercase $x$:** A specific value the variable can take.
        
    - _Example:_ $P(X = x)$ means "The probability that the random variable $X$ takes on the specific value $x$."
        

---

### **2. Types of Random Variables**

The choice of statistical model depends entirely on whether the variable is Discrete or Continuous.

#### **A. Discrete Random Variables**

- **Definition:** The variable can take on only a countable number of distinct values. There are "gaps" between values.
    
- **Examples:** Number of heads in 3 coin tosses ($0, 1, 2, 3$); Number of students in a class.
    
- **Function:** Described by a **Probability Mass Function (PMF)**.
    

#### **B. Continuous Random Variables**

- **Definition:** The variable can take on _any_ value within an interval. There are infinite possible values, and no gaps.
    
- **Examples:** Height ($175.24...$ cm), Time, Temperature.
    
- **Function:** Described by a **Probability Density Function (PDF)**.

### **3. Describing Probability Functions**

The mathematical rules for assigning probabilities differ for the two types.

#### **For Discrete Variables (PMF)**

The PMF gives the probability at a specific point.

- **Notation:** $P(X = x)$ or $p(x)$.
    
- **Rules:**
    
    1. $0 \le P(X=x) \le 1$ for all $x$.
        
    2. $\sum P(X=x) = 1$ (The sum of all probabilities is 1).
        

#### **For Continuous Variables (PDF)**

The PDF, denoted $f(x)$, describes the _shape_ of the curve.

- **Crucial Concept:** The probability of a continuous variable being exactly a specific value is **Zero**.
    
    - $P(X = 1.50000...) = 0$.
        
    - Why? Because there are infinite points. A single point has no width, and therefore no area.
        
- Area as Probability: We calculate probabilities over an interval (area under the curve).
    
    $$P(a \le X \le b) = \int_{a}^{b} f(x) \, dx$$
    
- **Rules:**
    
    1. $f(x) \ge 0$ (The curve cannot go below the x-axis).
        
    2. $\int_{-\infty}^{\infty} f(x) \, dx = 1$ (Total area under the curve is 1).
        

---

### **4. Cumulative Distribution Function (CDF)**

The CDF, denoted $F(x)$ (Capital F), is the "running total" of probabilities. It applies to both discrete and continuous variables.

- Definition: The probability that $X$ will take a value less than or equal to $x$.
    
    $$F(x) = P(X \le x)$$
    
- **Properties:**
    
    1. It is a non-decreasing function.
        
    2. Starts at 0 (left extreme) and ends at 1 (right extreme).
        
    3. Usefulness: Most statistical tables (like the Z-table) give you the CDF value. To find the probability of being greater than $x$, you use the complement:
        
        $$P(X > x) = 1 - F(x)$$
        

---

### **5. Expected Value and Variance**

Just as samples have Means ($\bar{x}$) and Variances ($s^2$), Probability Distributions have theoretical **Expected Values ($E[X]$)** and **Population Variances ($Var(X)$)**.

- Expected Value (The Mean $\mu$):
    
    The long-run average if you repeated the experiment infinite times.
    
    - _Discrete:_ $\mu = E[X] = \sum [x \cdot P(x)]$
        
    - _Continuous:_ $\mu = E[X] = \int x \cdot f(x) \, dx$
        
- Variance ($\sigma^2$):
    
    The weighted average of squared deviations.
    
    - _Formula:_ $\sigma^2 = E[(X - \mu)^2] = \sum (x - \mu)^2 P(x)$
        
    - _Shortcut Formula:_ $\sigma^2 = E[X^2] - (E[X])^2$
        

---

### **Important Notes, Tips & Facts**

- **The "PDF > 1" Trap:** For a **Continuous** variable, the density function $f(x)$ **can** be greater than 1. (e.g., If the entire distribution is squeezed between 0 and 0.1, the height must be high to make the area equal 1). However, a **Probability** $P(x)$ can never exceed 1.
    
- **Notation Capitalization:** Be strict with your notation.
    
    - $P(X < 3)$ refers to the random process.
        
    - $P(x < 3)$ is formally incorrect in many textbooks.
        
- **Discrete vs Continuous Equality:**
    
    - Discrete: $P(X \le 2)$ is **different** from $P(X < 2)$ because the value "2" matters.
        
    - Continuous: $P(X \le 2)$ is **identical** to $P(X < 2)$ because the single point "2" has zero probability.
