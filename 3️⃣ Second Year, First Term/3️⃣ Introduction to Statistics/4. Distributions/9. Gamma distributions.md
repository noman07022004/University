# 4.9 Gamma Distributions ⭐⭐⭐

**Rating Justification:**

- **Understanding (⭐ 3/5):** The Gamma distribution is the "parent" of several other important distributions (Exponential and Chi-Squared). While you rarely calculate raw Gamma probabilities by hand in an introductory course, understanding it unifies your knowledge of continuous distributions.
    
- **Exam (⭐ 2/5):** Direct questions on the general Gamma PDF are rare because the math requires integral calculus or software. However, knowing that the Chi-Squared distribution is a special case of the Gamma is a frequent theoretical question.
    

---

### **1. Introduction: The General Waiting Model**

In Subtopic 4.8, we learned that the **Exponential Distribution** models the waiting time for the **first** event in a Poisson process.

But what if we want to model the waiting time for the **$\alpha$-th** event?

- _Example:_ How long does it take for _5_ customers to arrive? How long until the _3rd_ component fails?
    

This is where the **Gamma Distribution** comes in. It is a flexible continuous distribution that represents the sum of independent, identically distributed (i.i.d.) exponential random variables.

---

### **2. The Gamma Function ($\Gamma$)**

Before defining the distribution, we must define the mathematical function that gives it its name. The Gamma Function is essentially a way to calculate **Factorials ($n!$)** for non-integer numbers.

- Definition:
    
    $$\Gamma(\alpha) = \int_{0}^{\infty} x^{\alpha-1} e^{-x} \, dx$$
    
- **Properties:**
    
    1. For any integer $n > 0$: $\Gamma(n) = (n-1)!$
        
    2. Recursive Property: $\Gamma(\alpha) = (\alpha - 1) \Gamma(\alpha - 1)$
        
    3. Value at 0.5: $\Gamma(0.5) = \sqrt{\pi}$ (Crucial for Normal distribution proofs).
        

---

### **3. The Probability Density Function (PDF)**

A random variable $X$ has a Gamma distribution with two parameters:

1. **Shape Parameter ($\alpha$ or $k$):** The number of events we are waiting for.
    
2. Rate Parameter ($\beta$ or $\lambda$): The rate at which events occur (same as Poisson/Exponential).
    
    (Note: Some textbooks use a "Scale" parameter $\theta = 1/\beta$. We will use Rate $\beta$ to stay consistent with the syllabus flow).
    

The Formula:

$$f(x) = \frac{\beta^{\alpha}}{\Gamma(\alpha)} x^{\alpha-1} e^{-\beta x}, \quad \text{for } x > 0$$

- $\frac{\beta^{\alpha}}{\Gamma(\alpha)}$: The normalizing constant (ensures area = 1).
    
- $x^{\alpha-1}$: Determines the shape (rising).
    
- $e^{-\beta x}$: Determines the decay (falling).
    

---

### **4. Special Cases (The Family Tree)**

The true power of the Gamma distribution is that it generalizes other familiar distributions.

- **Case 1: Exponential Distribution**
    
    - If we set $\alpha = 1$ (waiting for the first event), the Gamma formula simplifies exactly to the Exponential formula:
        
        $$f(x) = \beta e^{-\beta x}$$
        
- **Case 2: Chi-Squared Distribution ($\chi^2$)**
    
    - If we set **$\alpha = v/2$** and **$\beta = 1/2$** (where $v$ is degrees of freedom), we get the Chi-Squared distribution.
        
    - _Significance:_ This explains why sums of squared Normal variables (Topic 7) follow a Gamma-like shape.
        

---

### **5. Mean and Variance**

Because the Gamma distribution is essentially the sum of $\alpha$ independent Exponential variables, its moments are simply the sums of the Exponential moments.

- Mean (Expected Value):
    
    Recall Exponential Mean = $1/\beta$.
    
    $$\mu = E[X] = \frac{\alpha}{\beta}$$
    
- Variance:
    
    Recall Exponential Variance = $1/\beta^2$.
    
    $$\sigma^2 = Var(X) = \frac{\alpha}{\beta^2}$$
    

---

### **Important Notes, Tips & Facts**

- **Shape Evolution:**
    
    - If $\alpha \le 1$: The PDF looks like an Exponential curve (starts high, drops strictly).
        
    - If $\alpha > 1$: The PDF starts at 0, rises to a peak (mode), and then drops. It looks like a skewed bell curve.
        
    - If $\alpha$ is large: The distribution approaches a **Normal Distribution** (CLT effect).
        
- Additivity: If you have two independent Gamma variables with the same rate $\beta$ (e.g., $X_1 \sim Gamma(\alpha_1, \beta)$ and $X_2 \sim Gamma(\alpha_2, \beta)$), their sum is also Gamma:
    
    $$X_1 + X_2 \sim Gamma(\alpha_1 + \alpha_2, \beta)$$
    
    (Intuition: Waiting for 2 events + Waiting for 3 events = Waiting for 5 events).
