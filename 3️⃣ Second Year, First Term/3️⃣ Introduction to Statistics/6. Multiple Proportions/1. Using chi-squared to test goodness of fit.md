
# 6.1 Using Chi-Squared to Test Goodness of Fit ⭐⭐⭐⭐

**Rating Justification:**

- **Understanding (⭐ 4/5):** This topic introduces non-parametric testing for categorical data. It is conceptually distinct from the T-tests used for means. Understanding how to compare "Observed" reality against "Expected" theory is a fundamental skill in statistical modeling.
    
- **Exam (⭐ 5/5):** This is a very frequent exam topic. Questions usually present a theoretical distribution (e.g., "Mendelian genetics predicts a 9:3:3:1 ratio") and ask you to test if the collected data fits this theory.
    

---

### **1. The Conceptual Framework**

In previous topics (like the Z-test), we compared two groups against each other. In a **Goodness of Fit** test, we compare a _single_ group of data against a **theoretical distribution**.

- **The Question:** "Does this sample data fit the specific pattern we expect?"
    
- **Examples:**
    
    - **Fairness:** Does a die roll 1, 2, 3, 4, 5, 6 with equal frequency? (Uniform Distribution).
        
    - **Genetics:** Do the offspring of these plants follow the 3:1 dominant/recessive ratio?
        
    - **Business:** Do customer arrivals follow a Poisson distribution?
        

---

### **2. The Hypotheses**

Unlike other tests where $H_0$ usually implies "equality" or "zero difference," here $H_0$ implies "The model is correct."

- **Null Hypothesis ($H_0$):** The observed variable follows the specified distribution (e.g., $P_1 = 0.2, P_2 = 0.3, ...$). Any difference between Observed and Expected counts is due to random sampling error.
    
- **Alternative Hypothesis ($H_1$):** The observed variable does _not_ follow the specified distribution. The deviations are too large to be random.
    

---

### **3. The Calculation Steps**

The test statistic quantifies the "distance" between the data we gathered ($O$) and the data we predicted ($E$).

Step 1: Calculate Expected Frequencies ($E_i$)

For each category $i$, multiply the total sample size ($n$) by the theoretical probability ($p_i$) for that category.

$$E_i = n \times p_i$$

Step 2: Compute the Test Statistic ($\chi^2$)

For each category, find the difference, square it (to remove negatives), normalize it by dividing by the expectation, and sum them all.

$$\chi^2 = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i}$$

- $O_i$: Observed frequency in category $i$.
    
- $E_i$: Expected frequency in category $i$.
    
- $k$: Number of categories.
    

Step 3: Determine Degrees of Freedom ($df$)

For a simple Goodness of Fit test:

$$df = k - 1 - m$$

- $k$: Number of categories.
    
- $m$: Number of parameters estimated from the data to find the expected values (usually 0 if probabilities are given, but 1 if you have to calculate the mean from the data first, e.g., for Poisson).
    
- _Standard Exam Case:_ Usually just $k-1$.
    

---

### **4. The Decision Rule**

The Chi-Squared distribution is always non-negative and right-skewed.

- **If $\chi^2$ is small (near 0):** $O \approx E$. The fit is good. Fail to Reject $H_0$.
    
- **If $\chi^2$ is large:** $O$ is very different from $E$. The fit is bad. Reject $H_0$.
    

You compare your calculated statistic to the critical value $\chi^2_{\alpha, df}$ from the table.

---

### **5. Example: Testing a Die**

- **Scenario:** You roll a die 60 times.
    
- **Theory ($H_0$):** It is fair. $P(1)=P(2)=...=1/6$.
    
- **Expected ($E$):** $60 \times (1/6) = 10$ for each face.
    
- **Observed ($O$):** 12, 8, 11, 9, 15, 5.
    
- Calculation:
    
    $$\chi^2 = \frac{(12-10)^2}{10} + \frac{(8-10)^2}{10} + ... + \frac{(5-10)^2}{10}$$
    
    $$\chi^2 = \frac{4}{10} + \frac{4}{10} + \frac{1}{10} + \frac{1}{10} + \frac{25}{10} + \frac{25}{10} = \frac{60}{10} = 6.0$$
    
- **Critical Value ($df=5, \alpha=0.05$):** From table, $\approx 11.07$.
    
- **Conclusion:** Since $6.0 < 11.07$, we Fail to Reject. There is no evidence the die is unfair.
    

---

### **Important Notes, Tips & Facts**

- **The "Rule of 5":** The Chi-Squared approximation is mathematically invalid if sample sizes are too small.
    
    - **Condition:** Every Expected Count ($E_i$) must be **at least 5**.
        
    - **Fix:** If you have a category with $E < 5$ (e.g., a "Rare Disease" category), you must **combine** it with an adjacent category to boost the count before running the test. This reduces your degrees of freedom.
        
- **Directionality:** The Chi-Squared test is inherently **one-tailed (Right)**. We only care if the statistic is _large_. A value near 0 is never grounds for rejection (unless you suspect data fabrication).
    
- **Counts ONLY:** You can only put **Counts** (Integers) into the formula. Never plug in Percentages or Proportions directly.
