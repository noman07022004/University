## 📌 2.9: Contingent contracts (Overall: ⭐⭐⭐)

>**Rating Justification:**
>- **Understanding (⭐⭐⭐⭐):** Very important. This concept is the legal basis for all insurance, guarantees, and indemnity contracts. It's a contract where the _performance_ (not the _existence_) is conditional. Understanding this is key to real-world commercial law.
>- **Exam (⭐⭐⭐):** Moderately important. It's a common topic for short notes or as part of a problem question (e.g., distinguishing it from a wager, or deciding if the contract is void because the event became impossible).

A **Contingent Contract** is a contract where the primary obligation to perform is not absolute but is dependent on a future, uncertain event.

The **Contract Act, 1872,** defines it in **Section 31**:

> "A 'contingent contract' is a contract to do or not to do something, if some event, **collateral to such contract,** does or does not happen."

In simple terms, it’s a "wait and see" contract. The parties agree to a deal, but the main promise only becomes active _if_ a certain thing happens (or doesn't happen).

- **Core Concept:** The "contingent event" must be **collateral** to the contract. This means the event is _not_ the main performance itself or the consideration for the promise.
    
- **Example:** A contracts to pay B 100,000 Taka to repair B's house. This is a normal, absolute contract.
    
- **Contingent Example:** A contracts to pay B 100,000 Taka _if_ B's house is destroyed by fire. This is a **contingent contract** (an insurance policy). The fire is the uncertain future event, which is "collateral" (incidental) to the contract's main purpose (payment).
    

---

### 🔷 Key Rules for Enforcement

The **Contract Act, 1872, (Sections 32-36)** lays down the rules for when and how contingent contracts can be enforced.

#### 1️⃣ Enforcement on the "Happening" of an Event (Section 32) 
If the contract is contingent on a future event _happening_, it can only be enforced when that event has happened.

- **If the event becomes impossible:** The contract becomes **void**.
    
- **Example:** A contracts to pay B a sum of money when B marries C. C dies without marrying B. The contract becomes **void** because the event (B marrying C) has become impossible.
    

#### 2️⃣ Enforcement on the "Not-Happening" of an Event (Section 33) 
If the contract is contingent on an event _not_ happening, it can be enforced when the event becomes impossible.

- **Example:** A agrees to pay B a sum of money if a certain ship _does not_ return. The ship sinks. The contract can be enforced because the ship's return is now impossible.
    

#### 3️⃣ Enforcement on an Event linked to a Person's Conduct (Section 34) 
If the event is the future conduct of a living person (e.g., "when X does Y"), the event is considered to have become "impossible" if that person does something else that makes the original event impossible.

- **Example:** A agrees to pay B 10,000 Taka _if_ B marries C. Later, B marries D. The contract is now **void** because B's marriage to D has made the contingent event (B marrying C) impossible.
    

#### 4️⃣ Enforcement on an Event Happening within a Fixed Time (Section 35)

- If the contract is contingent on an event _happening_ within a fixed time (e.g., "if the ship returns within one year"), the contract becomes **void** if the time expires and the event hasn't happened, _or_ if the event becomes impossible before the time expires.
    
- If the contract is contingent on an event _not_ happening* within a fixed time, it can be enforced if the time expires and the event has _not_ happened.
    

#### 5️⃣ Agreement Contingent on an Impossible Event (Section 36) 
Any agreement contingent on an event that is _already impossible_ (whether the parties know it or not) is **void** from the beginning.

- **Example:** A agrees to pay B 1,000 Taka _if_ B can make two parallel straight lines meet. The agreement is **void**.

### 🔔 Important Notes & Tips

- **The "Collateral" Test:** This is the most important concept. The uncertain event must be _outside_ the main set of promises.
    
    - _Bad Example:_ "A promises to pay 100 Taka if B promises to sing." This is _not_ a contingent contract. B's promise _is_ the consideration; it's not a collateral event.
        
    - _Good Example:_ "A promises to pay B 100 Taka for singing, _if_ it rains tomorrow." The rain is the collateral event.
        
- **Contingent vs. Wager (Topic 2.10):** This is a critical distinction.
    
    - **Contingent Contract (Valid):** The parties have a _real interest_ in the event (e.g., insuring a house). The goal is to provide **indemnity or security**.
        
    - **Wagering Agreement (Void):** The parties have _no interest_ in the event _except for the bet_ (the money to be won or lost). The goal is pure **gambling**.
